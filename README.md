# AI-powered-instagram-bot

Overview
This bot features several algorithms designed to interact with Instagram. Please note that this repository is primarily for demonstration purposes and may require additional setup and customization for practical use.

Features:

* Random Hashtag Search: Developed an algorithm that randomly searches through an adjustable array of Instagram hashtags, allowing the bot to engage with a wider pool of Instagram posts.

* Automated Responses: Created a method that reads Instagram post descriptions and automatically generates responses using the ChatGPT API, allowing the bot to engage with users meaningfully. The method types in the response using humanized timing and then posts the response.

* Automatied Following, Liking, and Saving

* Automated Unfollowing

Disclaimer
This repository was created a while ago, and some of the div class names for the Instagram website may have changed. In order for the bot to work they need to be updated in the json file. However all the other logic in the code should work properly.
